# Spatial Simulation – assignments

This folder holds my Spatial Simulation assignments for this semester.
Files are named by assignment number.

- **Assignment 1** – `models/assignment1_savanna.gaml`: my hand-written Savannah model.
- **Assignment 2** – `models/assignment2_savanna_ai.gaml`: the Savannah model built with Claude Code.
  Its specification (`SPEC.md`), AI log (`AI_log.md`) and screenshots are in `docs/assignment2/`.
- **Assignment 3** – `models/assignment3_lion_demography.gaml`: lion demography model (ages in a list, report, red colour, death and birth).
  `models/assignment3_gemini_comparison.gaml`: Gemini one-prompt model, for comparison only.
  The design (`DESIGN.md`) and prompt log (`PROMPT_LOG.md`) are in `docs/assignment3/`.
